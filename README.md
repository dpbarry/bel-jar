# <img src="assets/logo.svg" alt="BelJar Logo" width="42" height="42" align="top"> BelJar

**BelJar** is a modern in-browser IDE for the [Beluga](https://github.com/Beluga-lang/Beluga) language. It uses `wasm_of_ocaml` to adapt the Beluga compiler into WebAssembly, which allows it to run entirely client-side. (`js_of_ocaml` as the slower fallback for old browsers)

It is currently in its beta stage. In the future, it can be a staging ground for experimental Beluga features.

Live at [beljar.deanbarry.com](https://beljar.deanbarry.com)
